ARCHITECTURE

Anatomy of the 4 Motion Engines

Each button is built without external heavy animation libraries—leveraging pure hardware-accelerated CSS3 and Web Audio oscillators.

01 // CYBER

Conic Laser Border & Glitch Sheen

Uses a dual-layered CSS conic-gradient rotating continuously behind an inner clipping mask. Upon hover, an automated horizontal chromatic dispersion bar sweeps across the typography with randomized keyframe glitching.

GPU Layer: transform: translateZ(0)
Border Rate: 3.5s linear infinite
VFX: Neon Spark Dispersion
02 // MERCURY

Magnetic Vector Tracking & Liquid Wave

Calculates Euclidean distance and pitch/yaw rotation angles relative to button center in requestAnimationFrame. Simultaneously, a cubic-bezier SVG liquid wave surges upward, creating an authentic fluid containment effect.

Max 3D Tilt: ±18 deg 3D Perspective
Spring Damping: cubic-bezier(0.34, 1.56, 0.64, 1)
Audio Wave: Frequency Modulated Sine Droplet
03 // WARP

Synthwave Depth Extrusion & Star Trails

Utilizes multi-layered stacked hard box-shadow offsets that mimic physical retro mechanical keyboard switches. On hover, star streaks shoot along the radial vector with rapid scale transformation and perspective grid movement.

Depth Layers: 4 Stacked Box Shadows
Depression Travel: 6px translateY on active
Audio Wave: Sawtooth Sub-Harmonic Boom
04 // PRISM

Frosted Glass & Magnetic Plasma Core

Leverages high-index backdrop blur filters with chromatic border shifting. A virtual plasma orb floats suspended inside the glass substrate, smoothly following cursor proximity with subtle lag for natural inertia.

Glass Filter: backdrop-filter: blur(18px)
Internal Inertia: 0.12 lerp factor
Audio Wave: High-Q Crystal Tri-Chime
