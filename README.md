# AETHER // Kinetic Interface Laboratory

A futuristic, hyper-interactive website homepage showcasing **4 next-generation animated button interaction paradigms** with fluid physics, quantum frosted glass, cyber neon conic laser borders, synthwave warp speed depth extrusion, and generative Web Audio synthesis.

## 🚀 Features

- **01 // Neon Overdrive (Cybernetic Laser Orbit)**:
  - 360° rotating CSS `conic-gradient` laser border beam.
  - Randomized horizontal glitch scanline with chromatic aberration text-shadow.
  - Corner HUD tech brackets and high-velocity electric spark VFX.
  - Pure Web Audio synthesizer: high-frequency laser sweep with exponential decay.

- **02 // Liquid Mercury (Hydrodynamic & Magnetic 3D)**:
  - True 3D magnetic cursor tracking (`rotateX`, `rotateY`, `perspective(600px)`).
  - Surging cubic-bezier fluid SVG liquid wave fill that rises from bottom to top.
  - Interactive specular light glare that tracks pointer coordinates.
  - Gelatinous squish/elastic jelly rebound upon click.
  - Pure Web Audio synthesizer: frequency-modulated fluid droplet bubble pop.

- **03 // Warp Speed (Retro Synthwave & Mechanical Extrusion)**:
  - 4-layer stacked depth shadows simulating physical retro mechanical switch travel.
  - Retro 80s arcade synthwave gradient face with glowing isometric perspective grid.
  - Radial starfield trails that accelerate outward into warp speed lines on hover.
  - Pure Web Audio synthesizer: deep sub-harmonic bass kick + rising saw sweep.

- **04 // Quantum Shard (Refractive Glass & Magnetic Core Orb)**:
  - Prismatic iridescent border with dynamic hue rotation.
  - High-index frosted glass backdrop blur (`backdrop-filter: blur(20px)`).
  - Floating internal magnetic plasma orb that tracks cursor proximity with inertia.
  - Pure Web Audio synthesizer: crystalline harmonic chord chime (C5, E5, G5, C6).

## 🛠️ Extra Interactive Capabilities

- **Interactive Background Particle Constellation**: Responsive HTML5 Canvas with floating velocity nodes that connect dynamically with glowing lines and repel from cursor proximity.
- **Audio Synthesizer Engine**: 100% self-contained sound effects generated programmatically with the browser's Web Audio API—no external audio files or network requests required! Includes an SFX mute/unmute toggle in the navigation bar.
- **VFX Particle Shockwaves**: Real-time click position tracking generating radial spark explosions and expanding shockwave rings.
- **Real-Time Telemetry & Console**: Live terminal feed logging every user event, interaction counter, last triggered button status, and 60 FPS performance counter.
- **Dynamic Theme Palette Switcher**: Seamlessly cycle between 4 atmospheric palettes (*Aurora*, *Sunset*, *Cyber*, *Matrix*).
- **Synchronized Salvo**: One-click demo button to fire all 4 buttons in a staged cascade!
